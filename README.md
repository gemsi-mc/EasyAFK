# ⭐ **EasyAFK - A Simple but Powerful AFK System**

**EasyAFK** is a lightweight yet feature-rich AFK system designed to make player inactivity management effortless. Perfect for SMPs, community servers, or any setup where AFK behaviour needs to be controlled, displayed, or automated.

The mod handles everything from **AFK detection**, **tab-list indicators**, **title notifications**, **broadcast messages**, **kick timers**, and optional **protections** — all fully configurable.
